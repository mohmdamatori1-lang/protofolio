Social media team website

I developed the Foueek Social website as an interactive social media platform using HTML, CSS, and JavaScript. First, I built the structure with HTML, creating essential pages such as the login, sign-up, news feed, profile, and messaging sections. Then, I used CSS to style the interface with a modern, responsive design — including a dark mode option, colorful user profiles, and a smooth navigation bar. To make the platform dynamic, I implemented JavaScript for real-time features like posting updates, liking and commenting on posts, following users, and displaying notifications. I also added local storage to save user data temporarily for demo purposes, allowing users to experience social media interactions without a backend server. The result is a fully functional, visually engaging social media prototype called “Foueek Social” that simulates core social networking features directly in the browser.

Personal Protofolio

I built my personal portfolio website from scratch using HTML, CSS, and JavaScript to showcase my skills, projects, and experience as a web developer. First, I structured the layout with HTML, creating clear sections such as Home, About, Services, Projects, and Contact. For the visual design, I used CSS to create a fully responsive and modern interface — including a navigation bar, grid-based project gallery, hover effects, and smooth scrolling. I also implemented a light/dark mode toggle using JavaScript to enhance user experience. To make the portfolio interactive, I added JavaScript features like a dynamic typing effect in the hero section, form validation for the contact page, and filterable project categories. I also used local storage to save user theme preferences. The result is a professional, fast, and visually appealing portfolio that works seamlessly on all devices — from desktops to mobile phones — demonstrating my front-end development abilities in a practical, real-world project.

Daily Expense Tracker App
